# ⚖️ Agente Jurídico - Analizador Normativo

## Objetivo

Crear una aplicación que permita subir un PDF y analizarlo
contra un conjunto de normas para detectar:

- Cumplimientos
- Incumplimientos
- Aspectos a revisar
- Normativa aplicable
- Artículos relacionados
- Evidencia encontrada en el documento
- Página donde se encuentra la evidencia

El sistema será una herramienta de apoyo para la revisión documental.
